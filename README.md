Seats-Assignment

학교에서 사용할 수 있는 자리 배치 프로그램입니다. 학생을 추가하고, 자리를 무작위로 추첨하거나 직접 배치할 수 있으며, 특정 좌석을 고정하는 기능도 제공합니다.

✨ 주요 기능

🎲 자리 추첨

자리 추첨 버튼을 클릭하면 학생들의 자리가 무작위로 배치됩니다.

고정된 좌석은 유지되며, 나머지 좌석만 다시 추첨됩니다.

🪑 자리 배치

자리 배치 버튼을 클릭하면 배치 모드가 시작됩니다.

6 × 7 크기의 자리표에서 학생들을 배치할 좌석을 선택할 수 있습니다.

학생 수만큼 좌석을 선택한 뒤 자리 배치 버튼을 다시 클릭하면 배치 모드가 종료됩니다.

선택한 좌석에 학생들이 순서대로 배치됩니다.

🔒 자리 고정

자리 고정 버튼을 클릭하면 고정 모드가 시작됩니다.

학생이 앉아 있는 좌석을 클릭하면 해당 좌석이 고정됩니다.

같은 좌석을 다시 클릭하면 고정이 해제됩니다.

자리 고정 버튼을 다시 클릭하면 고정 모드가 종료됩니다.

고정된 좌석의 학생은 자리 추첨을 해도 자리가 바뀌지 않습니다.

🔢 자리 지정

학생이 앉아 있는 좌석을 클릭하면 학생 번호를 입력할 수 있는 창이 나타납니다.

원하는 학생의 번호를 입력하면 해당 학생과 선택한 좌석의 위치가 서로 바뀝니다.

➕ 학생 추가 및 삭제

학생의 번호와 이름을 입력하여 학생 목록에 추가할 수 있습니다.

추가된 학생은 빈 좌석 중 하나에 자동으로 배정됩니다.

학생 목록에서 해당 학생의 X 버튼을 클릭하면 학생이 삭제되며, 자리표에서도 해당 학생이 제거됩니다.

학생 번호는 중복해서 등록할 수 없습니다.

등록 가능한 학생 수는 최대 42명입니다.

📸 스크린샷 화면

스크린샷 화면 버튼을 클릭하면 스크린샷 촬영에 적합한 자리표 화면으로 전환됩니다.

자리표의 줄 수를 1~7개로 조절할 수 있습니다.

자리표의 구분선 표시 여부를 설정할 수 있습니다.

돌아가기 버튼을 클릭하면 원래 화면으로 돌아갈 수 있습니다.

🛠️ 개발 환경

Engine: Unity 6

Language: C#

UI: Unity UI, TextMeshPro

📖 사용 방법

학생의 번호와 이름을 입력하여 학생 목록을 구성합니다.

자리 추첨 버튼으로 무작위 자리 배치를 진행하거나, 자리 배치 모드에서 원하는 좌석을 직접 선택합니다.

필요한 경우 자리 고정 기능으로 특정 학생의 좌석을 유지합니다.

자리 지정 기능으로 특정 학생의 위치를 변경할 수 있습니다.

스크린샷 화면에서 자리표의 줄 수와 구분선을 설정한 뒤 결과를 캡처합니다.

🎯 개발 목적

학교에서 학생들의 자리를 편리하게 배치하고, 무작위 추첨과 직접 배치를 함께 활용할 수 있도록 제작한 프로그램입니다.
